# Админка ЭлДент

Рабочая русская система управления содержимым: сервер Node.js и база SQLite. Это собственная админка; Directus не установлен. Интерфейс содержит семь разделов: Главная, О клинике, Услуги, Врачи, Цены, Контакты, Документы.

## Начало работы

1. На компьютере должен быть установлен Node.js 24 LTS.
2. Откройте терминал в папке проекта и выполните `npm run start:cms`.
3. Откройте http://127.0.0.1:4175/admin/ и создайте свой логин и пароль. Пароль должен содержать не менее 12 символов.
4. Сам сайт открывается по адресу http://127.0.0.1:4175/preview/index.html.

На Mac для запуска также можно дважды нажать `start-admin.command`. Зависимости npm для запуска CMS не требуются: сервер использует встроенные возможности Node.js. Пока сервер работает, окно терминала нужно оставить открытым.

## Редактирование

Откройте раздел, измените поля и нажмите «Сохранить черновик». Черновик не показывается посетителям. Кнопка «Опубликовать» публикует все сохранённые разделы. Уход с несохранёнными изменениями требует подтверждения. Можно добавлять, удалять, перемещать и скрывать записи; цены сгруппированы по категориям. Фото: JPG, PNG, WebP; документы: PDF; предел загрузки 10 МБ. Изменения появляются на сайте после обновления страницы.

История и фотография в разделе «О клинике» необязательны. Если поля пустые, дополнительные блоки не выводятся. Форма записи на главной пока демонстрационная: она не передаёт заявки в клинику.

## Данные и резервные копии

Данные сохраняются в `.cms-data/content.sqlite`, файлы — в `.cms-data/uploads`. После закрытия браузера и перезапуска сервера содержимое остаётся. Сессии входа хранятся в памяти и завершаются при перезапуске; срок сессии — 8 часов.

В разделе «Обзор» доступна выгрузка JSON с черновиком, опубликованными данными и историей публикаций, без пароля. Файлы в эту выгрузку не входят. Полная резервная копия — папка `.cms-data` после остановки сервера. Автоматический импорт выгрузки через интерфейс пока не реализован.

## Перенос на хостинг

Нужен сервер с Node.js 24, постоянным диском и HTTPS. Статический хостинг и стандартный Sites Worker-шаблон не запускают этот SQLite-сервер. Настройте запуск `npm run start:cms` под менеджером процессов и HTTPS-прокси к 127.0.0.1:4175. Прокси должен передавать исходный Host. API и страницы должны работать на одном домене.

Переменные: PORT (4175), HOST (127.0.0.1), CMS_DATA_DIR (путь к базе и загрузкам), CMS_SECURE_COOKIE=1 (обязательно при HTTPS). Создайте администратора до внешнего доступа, затем переносите базу и загрузки. Настройте регулярные резервные копии, права на файлы и обновления Node.js.

Текущая версия предназначена для одного администратора. Роли, смена и восстановление пароля через интерфейс, медицинские записи, интеграция заявок и массовый импорт не реализованы. Перед публичным запуском требуется проверка настройки сервера и отдельная проверка безопасности. Сейчас это локальная рабочая версия для редактирования содержимого, а не опубликованный сервис.
