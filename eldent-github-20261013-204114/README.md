# ЭлДент — сайт стоматологической клиники

Исходный код сайта и панели управления содержимым.

## Запуск сайта

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
npm run test:sites
```

## Панель управления

Используйте Node.js с поддержкой `node:sqlite`.

```sh
npm run start:cms
```

Подробности в `cms/README.md`. Локальная база и учётные данные администратора не включены в репозиторий.

## Структура

- `src/` — приложение, цветовая тема кнопок и исходники админки.
- `public/preview/` — страницы сайта, шрифты и изображения.
- `cms/` — сервер CMS и начальное содержимое.
- `scripts/`, `worker/`, `.openai/` — сборка и подготовка к размещению.
- `tests/` — проверки CMS и сборки.

Демонстрационная форма не отправляет заявки. Изображение интерьера — иллюстрация для макета.
